# AFTER2046 LABS

记录、实验与构建 2046 之后的世界。

纯静态个人网站，单个 `index.html`，无需构建。

## 文件

| 文件 | 说明 |
|------|------|
| `index.html` | 网站全部页面与样式（LOGO 已内嵌） |
| `assets/wordmark.png` | 透明字标 |
| `assets/mark.png` | 透明 "A" 图标 |
| `assets/favicon.png` | 网站图标 |
| `assets/og.jpg` | 社交分享预览图 |

## 配色

右上角五个色点可切换全站主题：ICE / GOLD / VIOLET / MONO / PAPER，对应 LOGO 的五套配色。

## 发布

Settings → Pages → 选择 `main` 分支根目录，网址为 `https://117460234qq-ctrl.github.io/blog/`。
